# Contenu livré avec le site

Déposez ici un fichier **`bundle.json`** exporté depuis `/admin → Releases →
Exporter le contenu`.

S'il est présent, il devient le **contenu de référence** de l'application : au
prochain déploiement, tous les appareils reçoivent vos créatures, vos textes,
votre carte et vos images — sans Firebase, sans serveur.

Sans ce fichier, l'application utilise le contenu compilé dans son code
(`src/content/`). C'est le cas par défaut.

Voir `docs/MEDIA.md`.
